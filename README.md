# 🚀 ProblemX — Solve Beyond Limits

**ProblemX** is a LeetCode-inspired coding practice platform designed to help developers improve their problem-solving skills, practice programming challenges, and track their coding progress through a clean, interactive interface.

## 🌟 Features

- **Coding Practice Interface** — A dedicated workspace for solving programming problems.
- **Code Editor** — Write and edit code in a focused editor.
- **Problem Workspace** — View problem descriptions alongside the coding area.
- **Test Cases** — Explore test cases and view execution results.
- **Problem Difficulty** — Identify problems by difficulty levels: Easy, Medium, and Hard.
- **User Profiles** — Display coding activity, achievements, and profile information.
- **Progress Tracking** — Visualize solved problems and practice statistics.
- **Activity Heatmap** — View coding activity over time.
- **Search & Filtering** — Find problems more easily.
- **Dark & Light Themes** — Switch between comfortable viewing modes.
- **Responsive Design** — Adapt the interface to desktop and mobile screens.

## 🚀 Getting Started

